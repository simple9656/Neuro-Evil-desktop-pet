Neuro / Evil Neuro 原版修复包
============================

此包直接基于你提供的 neuro_shim.rar 和 evil_neuro_shim.rar 内容制作，保留原始 JAR、图片和行为配置；只修正 Neuro 包的异常目录结构，并添加简体中文语言选择和 Java 8 启动器。

1. 克隆或下载整个文件夹后解压，不要直接从 ZIP 预览中运行。
2. 双击“启动Neuro.cmd”或“启动Evil.cmd”。
3. 已内置 32 位和 64 位 Java 8，启动器会根据 Windows 位数自动选择，并设置简体中文；不需要另装 Java。
4. 退出时右键桌宠托盘图标，选择关闭全部桌宠。

注：这是两个 RAR 原版引擎，没有升级为合集中的新版引擎。旧版 Java/JNA 与系统桌面组件的兼容性有限，未保证适用于每个 Windows 版本。
